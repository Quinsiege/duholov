# Духолов

Гео-игра в духе Pokémon GO для Android-смартфона.

**Сеттинг.** 2031 год. Геомагнитная буря — «Тонкая ночь» — истончила границу между Явью и Навью. По улицам бродят духи: древние (Леший, Водяной, Домовой, Кикимора) и новые, городские (Вайфайка, Трамвайник, Фонарник, Сетевик). Ты — Ловчий Ордена Оберега.

## Что есть в игре

- **Реальная карта** (OpenStreetMap) и твоя GPS-позиция. Днём светлая карта, ночью — тёмная.
- **27 духов** шести стихий (Огонь, Вода, Лес, Ветер, Ток, Тень): 6 цепочек превращений, одиночные редкие духи и 2 легенды (Жар-птица, Кощей). Вся графика нарисована кодом (SVG), картинки не нужны.
- **Детерминированный мир**: в одной точке в одно время всегда одни и те же духи. У каждого района своя любимая стихия, ночью чаще попадаются Тень и Ветер.
- **Ловля**: оберег бросается свайпом, кольцо сжимается («Хорошо / Отлично / Превосходно»), цвет кольца показывает сложность, дух покачивается в обереге, может вырваться и сбежать. Есть мёд, серебряные и золотые обереги, **AR-режим с камерой**.
- **Родники** (аналог покестопов): обереги, мёд, живая вода, ладан, коконы. Перезаряжаются 5 минут.
- **Разломы** (рейды): босс меняется каждый час. Тап — атака, особый приём по шкале энергии, уклонение свайпом или кнопкой. После победы босса можно поймать.
- **Коконы** (яйца) на 2/5/10 км вылупляются, пока ты ходишь.
- Уровни Ловчего (до 40), усиление и превращение духов (искры и эссенция), оценка духов, бестиарий, задания дня с сундуком, ладан.
- Звук синтезируется в коде, есть вибрация. Прогресс сохраняется на телефоне.

### Новое в v1.1
- **Погода.** Настоящая погода из Open-Meteo (координаты округляются до ~1 км, можно отключить в настройках) усиливает две стихии: таких духов больше, они сильнее, дают +25% искр, а в разломах наносят +20% урона. На карте идут дождь, снег, туман и ветер. Без сети погода моделируется.
- **Луна.** В полнолуние ночью выходят Русалки и Навки, в новолуние сияющие духи встречаются вдвое чаще.
- **Сияющие духи**: редкие цветовые варианты (1/128, из коконов 1/64, в разломах 1/20), отмечаются в бестиарии.
- **Спутник** ходит рядом с игроком на карте и каждые 1/3/5 км приносит эссенцию, а иногда и предметы.
- **Знаки Ордена**: 15 медалей с бронзовой, серебряной и золотой ступенью и наградой опытом.
- **Летопись Ордена**: 6 сюжетных глав с наставником Велимиром; финальная награда — встреча с Жар-птицей.
- Сила броска нормируется по высоте экрана.

### Новое в v1.2
- **Капища Ордена** (с 3 уровня) — поединки 3 на 3 с хранителями, которые меняются каждый день. Тап — быстрая атака и энергия; «Приём» — особый удар, который можно усилить, быстро тапая по сфере; по 2 щита у каждой стороны; смена духа с перезарядкой 25 с. Три ранга хранителей (Ученик, Мастер, Старейшина) подстраиваются под силу твоих духов. Победа освящает капище до конца дня.
- **События недели** меняются по понедельникам (11 по кругу): недели стихий, Звездопад (двойной опыт), Родниковая неделя, Навья неделя, Неделя коконов, Неделя разломов, Неделя поединков.
- **Процедурная музыка** на WebAudio: спокойные «гусли» с эхом на карте и ритмичная тема в битвах. Отключается в настройках.
- **Команда** для разломов и капищ выбирается вручную (или автоматически — три сильнейших).
- **Массовое отпускание** в коллекции: режим «Выбрать» и кнопка «Лишние» (оставляет сильнейшего каждого вида; избранные, сияющие, спутник и команда защищены).
- Новый знак «Поединщик» и задание дня «Победи хранителей капищ».

Отправленные посылки хранятся в списке.

### Версия 2.0.0 — выход в прод
- **Автообновление**: при входе в игру (и при возвращении в неё) клиент сверяет свою версию с `version.json` на сервере. Если вышла новая — обязательное окно «Доступно обновление» со списком изменений; кнопка «Обновить» сохраняет прогресс, сбрасывает кэш кода и перезагружает игру. Проверить вручную: «Настройки → Проверить обновления».
- **Приложение для Android** открывает игру с сайта — обновления игры приходят без переустановки. Без сети — страница «Нет подключения». Если устареет само приложение-обёртка (`minApk` в `version.json`), игра попросит скачать новый APK.
- **Тестовое убрано из прода**: демо-режим с джойстиком и предпросмотр праздников `?hol=` работают только на локальном сервере разработки; автотесты перенесены из сайта в папку `tests/`.

### Версия 2.1.0 — настоящие места и прогресс на сервере
- **Родники, Капища и Разломы стоят у реальных объектов.** Телефон загружает из OpenStreetMap (Overpass API) памятники, храмы, фонтаны, арт-объекты, парки, смотровые площадки и т. п. квадратами ≈ 1 км, ближние первыми, и хранит их неделю. Отбор детерминирован (`www/js/osm.js`): у всех игроков одни и те же места. Храмы — только Родники; Разломы открываются на час у части Капищ.
- **Места от игроков.** «Меню → Места» (с 5 уровня): снимок делается только камерой в игре; в момент съёмки фиксируется GPS (точность не хуже 30 м), координаты и время записываются в сам файл (EXIF) и в заявку. Точку объекта можно сдвинуть не дальше 50 м от места съёмки — это же проверяет база (ограничение `geotag_match`). Не больше 5 заявок в сутки. За одобренное место — награда.
- **Модерация**: https://quinsiege.github.io/duholov/admin.html — вход по ссылке на почту. Панель показывает снимок, сверяет геометку в файле с заявкой, показывает место съёмки и соседние объекты на карте; модератор одобряет (можно поправить название и тип) или отклоняет с причиной. Во вкладке «Объекты на карте» можно скрыть, переименовать или сменить тип любого места, в том числе из OpenStreetMap.
- **Прогресс хранится на сервере** (таблица `saves`, доступ только к своей строке). На телефоне — рабочий кэш для игры без связи; изменения уходят на сервер пачкой (~30 с) и сразу при сворачивании игры. Если на сервере версия новее — побеждает сервер. Перенос на другой телефон — одноразовым кодом («Настройки → Перенести на другое устройство»), старое устройство после переноса предлагает начать заново. Резервная копия в файл убрана.
- Если в радиусе 1 км нет ни одного Родника, раз в сутки приходит «Посылка из Ордена» с оберегами.
- После обновления игра показывает окно «Игра обновлена» со списком изменений.

### Версия 3.0.0 — все действия через сервер
- **Прогресс меняет только сервер игры** — Supabase Edge Function `game` (`server/game/core.js` + `serve.js`). Телефон присылает намерение (`encThrow`, `spring`, `powerUp`, `raidEnd`…), сервер проверяет его и отвечает изменениями прогресса (`www/js/diff.js`) и событиями (новый уровень, знак, задание). Телефон ничего не пишет в прогресс сам (в режиме разработки это проверяется: правка в обход сервера выводит ошибку в консоль).
- **Что проверяет сервер**: дух действительно есть на карте в этом месте и в это время (тот же детерминированный `world.js`); игрок рядом с родником/капищем/разломом; перезарядки, лимиты в час и сутки; предметы в сумке; шанс поимки, покачивания и побег — бросает сервер (попадание и кольцо — ловкость игрока, их присылает телефон); победа в бою засчитывается, только если команда могла нанести столько урона за это время (`rules.js`); пройденный путь — по точкам GPS, не быстрее 9 м/с; скачки координат быстрее ~200 км/ч включают паузу.
- **Подарки друзьям** — через сервер (`gifts`), одной кнопкой; **посылки с духами** — короткий код `DUH2.XXXXXXXXXX` (`trades`), открыть можно один раз.
- **Строку таблицы Лиги** пишет сервер после турнира (если в настройках разрешено показывать себя в таблице).
- **Нужен интернет**: без связи игра показывает «Нет связи с Навью» и ждёт. Настройки (звук, AR, тема карты) и последняя точка карты хранятся на телефоне.
- Время игры: «сейчас» — по часам сервера, «сегодня», ночь и праздники — в часовом поясе игрока (`U.now`, `U.local`).
- Сервер собирается из общих модулей скриптом `tools/build-server.ps1` в `server/functions/game/index.ts` (CI проверяет, что сборка свежая). Развёртывание: Supabase → Edge Functions → `game` → код этого файла, «Verify JWT» выключен (функция сама проверяет вход).

### Версия 3.1.0 — общее дело Ордена и серия дней
- **Общее дело Ордена** («Меню → Задания → Орден»): все Ловчие неделю (с понедельника, по UTC) вместе копят очки — поимка, родник, 500 м пути — 1, кокон, победа в капище, вторжение — 3, разлом — 5. Событие недели удваивает очки своего дела (неделя стихии — поимки духов этой стихии по 3 очка). Цель — `max(300, 120 × участники)`, три ступени (⅓, ⅔ и вся цель); награду ступени забирает каждый, кто сам внёс 15 / 40 / 80 очков. Награды прошлой недели можно забрать всю следующую неделю. Видна десятка лучших Ловчих недели.
- Очки считает сервер по изменению счётчиков прогресса после каждого запроса (`Rules.orderPoints`), вклад пишется в `order_players` (`server/006_order.sql`), итоги недели — функция `order_stats`. Телефону доступа к таблице нет.
- **Серия дней**: первый вход за день (по часам игрока) — награда, растущая 7 дней по кругу, на 7-й день кокон 10 км. Пропуск дня начинает серию заново.
- Новые знаки: «Верность» (7 / 30 / 100 дней подряд) и «Соратник» (100 / 1000 / 10 000 очков общего дела).

### Версия 3.2.0 — поручения родников и профиль друга
- **Поручения родников**: родник выдаёт поручение (первое за день — всегда, дальше — в каждом четвёртом, одновременно до 5). Лёгкие (поймать, зачерпнуть, усилить, сфотографировать), средние (стихия, отличные броски, путь, превращение, капище) и трудные (кокон, вторжение, разлом). За выполненное — предметы и встреча с духом: обычным/необычным, необычным/редким или редким/эпическим (без легенд, региональных и сезонных). Такой дух ловится в 1,5 раза легче и не сбегает — встреча ждёт в «Заданиях», пока он не пойман. Ненужное поручение можно выбросить.
- **Профиль друга**: коснись друга в «Друзьях» — уровень, когда был в игре, спутник, три сильнейших духа, поймано / видов / пройдено / разломов / золотых знаков / ранг Лиги. Сервер отдаёт профиль, только если дружба взаимная, и пропускает из чужого сохранения лишь числа и известные облики. В списке друзей — их настоящий облик.

Первая победа за день над каждым другом — 800 опыта, ✦ 500, обереги, мёд и +1 ★ дружбы; дальше — тренировка (+100 опыта). Победа проверяется, как в капищах (`plausibleDuel`). ### Версия 3.4.0 — места по всей России
- **Объекты OpenStreetMap всей России хранятся в базе игры** (таблица `pois`, `imported = true`). Раз в неделю (по понедельникам) workflow **«Места России»** (`.github/workflows/places.yml`) скачивает свежую выгрузку России с Geofabrik, отбирает объекты (`tools/osm-import/filter.txt`, `build.py` — те же правила, что у телефона, плюс дома культуры, почты, станции и платформы) и загружает их (`load.sql`): новые добавляются, изменившиеся обновляются, исчезнувшие удаляются. Правки модераторов и места игроков (`edited = true`) импорт не трогает. Неполная выгрузка (меньше 150 000 мест) в базу не попадает.
- **У каждого населённого пункта есть места**: если у центра деревни в радиусе 400–700 м нет ни одного объекта, там появляется Родник «Околица …» (у городов — «Центр …»); в сёлах и городках с двумя и более местами одно обязательно становится Капищем (а у Капищ открываются Разломы).

- Настройка: `server/007_places_russia.sql`; секрет репозитория `SUPABASE_DB_URL` — строка подключения Session pooler из Supabase (Connect). Без секрета workflow только собирает места (CSV в артефакте запуска).

## Как выпускаются изменения
Ветка `main` защищена: изменения попадают в прод **только через Pull Request**.

1. Новая ветка от `main`: `feature/<что-то>` или `fix/<что-то>`; коммиты с понятными сообщениями.
2. Если изменение должно дойти до игроков — поднять версию (семантически: `исправление` → 2.0.**1**, `новое` → 2.**1**.0):
   - `www/js/version.js` → `APP_VERSION`,
   - `www/version.json` → `version` и `notes` (эти строки игроки увидят в окне обновления).
   CI проверяет, что версии совпадают.
   Свои скрипты и стили подключаются с меткой `?v=dev` (в `index.html`, `admin.html` и списке `sw.js`); при публикации CI меняет её на номер версии, чтобы CDN GitHub Pages не отдавал игрокам смесь старых и новых файлов. Забытую метку поймает CI.
3. Если меняется Android-обёртка: `WRAPPER_VERSION` в `MainActivity.kt` = `versionCode` в `android/app/build.gradle.kts` = `minApk` в `www/version.json`.
4. `git push` ветки → Pull Request в `main`. Workflow **«Проверки»** запускает автотесты в Chromium (`tests/`) и сборку APK.
5. Когда проверки зелёные — слияние (squash). Workflow **«Публикация»** снова прогоняет тесты, собирает APK и выкладывает сайт; открытые клиенты получат окно обновления.

## Подключение сервера (Supabase, бесплатно)
1. supabase.com → **Sign in with GitHub** → **New project** (регион — ближайший, пароль БД сохраните у себя).
2. **Authentication → Sign In / Providers → Anonymous sign-ins: включить.**
3. **SQL Editor** → по очереди выполнить `server/supabase.sql`, `server/002_objects_and_saves.sql`, `server/003_osm_on_clients.sql`, `server/004_friends.sql`, `server/005_server_authority.sql`, `server/006_order.sql`, `server/007_places_russia.sql`; развернуть Edge Function `game` (см. «Версия 3.0.0»).
   **Authentication → URL Configuration**: Site URL = адрес игры, Redirect URLs = `<адрес игры>/**` (для входа модераторов по ссылке из письма).
4. **Project Settings → API Keys**: **Project URL** и **publishable key** → `www/js/config.js` (публичные параметры; секретные ключи в игру не кладите никогда).
5. Изменение — через Pull Request, как описано выше.
6. **Модератор**: открыть `admin.html`, войти по ссылке из письма — панель покажет ID учётной записи. Затем в SQL Editor: `insert into public.admins (user_id) values ('<ID>');`
