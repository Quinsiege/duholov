# Духолов в Google Play

Версия для Google Play — сборка `play` приложения (Android 16 / API 36, приложение 11+):

- покупки в Казне — **только через Google Play Billing** (ЮKassa в ней не показывается);
- обновление приложения — только через Google Play (без скачивания APK с сайта);
- файл для Play Console — **AAB**: Actions → запуск «Публикация» → Artifacts → `duholov-play-aab`.

Сайт и APK с сайта (сборка `site`) остаются как были — с ЮKassa.

> **Деньги.** Google не проводит покупки и не платит разработчикам, у которых счёт для выплат в российском банке
> (с 26.12.2024, [справка Google](https://support.google.com/googleplay/android-developer/answer/15685001)).
> Для покупок в Казне нужен **банковский счёт** за рубежом (карта для выплат не подходит). Игрокам в России Google Play
> покупки тоже не проводит ([справка](https://support.google.com/googleplay/android-developer/answer/11950272)):
> им Казна покажет «Покупки через Google Play недоступны на этом устройстве или в твоей стране». Остальная игра работает.

## 1. Аккаунт разработчика

1. https://play.google.com/console/signup — личный аккаунт, взнос 25 $ (зарубежной картой), проверка личности.
2. Платёжный профиль (Настройка → Платёжный профиль) — **счёт для выплат в зарубежном банке**.
3. Личному аккаунту перед выпуском нужен закрытый тест: не меньше 12 тестировщиков 14 дней подряд.

## 2. Приложение и подпись

1. «Создать приложение»: название «Духолов», игра, бесплатная.
2. Пакет — `ru.duholov.game` (задаётся первым загруженным AAB).
3. **Подпись — тем же ключом, что APK с сайта** (иначе версия из Play и APK с сайта не обновляют друг друга):
   Настройка → Целостность приложения → Подпись приложений Google Play → «Использовать свой ключ» →
   инструкция Google с инструментом PEPK: ключ `duholov.jks` (тот, что в секрете ANDROID_KEYSTORE_BASE64), псевдоним `duholov`.
   Этот шаг делает владелец — ключ и пароль секретные.
4. Закрытое тестирование → загрузить `duholov-play.aab` → добавить тестировщиков.

## 3. Наборы златников (товары)

Монетизация → Товары → Внутриигровые товары → создать 5 товаров (идентификатор — ровно такой, тип — разовый):

| Идентификатор | Название | Златники | Цена-ориентир |
|---|---|---|---|
| `z100` | 100 златников | 100 | 0,99 $ |
| `z330` | 330 златников (+10%) | 330 | 2,99 $ |
| `z575` | 575 златников (+15%) | 575 | 4,99 $ |
| `z1200` | 1200 златников (+20%) | 1200 | 9,99 $ |
| `z2600` | 2600 златников (+30%) | 2600 | 19,99 $ |

Число златников задаёт сервер игры (Rules.PAY), а не Play: цену можно менять, идентификаторы — нет.
Товары активировать («Активен»). Цены в валюте игрока Play пересчитает сам.

## 4. Ключ для проверки покупок (сервер игры)

Сервер сам проверяет каждую покупку у Google (Google Play Developer API), начисляет златники и «потребляет» покупку.

1. https://console.cloud.google.com → проект (любой) → «API и сервисы» → включить **Google Play Android Developer API**.
2. IAM → Сервисные аккаунты → создать (например, `duholov-play`) → Ключи → Добавить ключ → JSON → скачается файл.
3. Play Console → Пользователи и разрешения → Пригласить → почта сервисного аккаунта (`…@….iam.gserviceaccount.com`) →
   разрешения на приложение «Духолов»: **Просмотр финансовых данных** и **Управление заказами и подписками**.
4. Файл ключа — на сервер и в секреты функции (файл после этого удаляется):
   ```bash
   scp -i ~/.ssh/duholov_ed25519 ~/Downloads/ключ.json root@147.45.100.117:/root/gplay.json
   ssh -i ~/.ssh/duholov_ed25519 -t root@147.45.100.117 duholov-secrets
   ```
   На все вопросы — Enter (оставить как есть), на «Файл ключа» — `/root/gplay.json`.

Возвраты и отмены: раз в час (при открытии Казны любым игроком) сервер смотрит отменённые покупки Google Play и списывает
начисленные по ним златники. Чеки «Мой налог» по покупкам в Google Play не пробиваются (продаёт Google).

## 5. Анкеты Play Console

**Политика конфиденциальности:** https://duholov.ru/privacy.html
**Удаление аккаунта (ссылка для «Безопасность данных»):** https://duholov.ru/delete.html — удалить можно и в игре
(Меню → Настройки → Удалить учётную запись).

**Безопасность данных** — собираются, не передаются третьим лицам (сервисы-исполнители не считаются), шифруются при передаче,
игрок может запросить удаление:

| Тип данных | Зачем | Обязательно |
|---|---|---|
| Точное местоположение | функции приложения (карта, духи, места) | да |
| Имя (имя Ловчего; имя из Google / VK / Telegram при входе) | функции, аккаунт | да |
| Идентификаторы пользователя (id учётной записи, код игрока) | функции, аккаунт | да |
| Фото (снимки предлагаемых мест) | функции | нет |
| История покупок | функции (начисление златников) | нет |
| Другие сообщения в приложении (чат Ордена) | функции | нет |
| Действия в приложении (прогресс игры) | функции | да |
| Журналы сбоев | аналитика (ошибки) | да |

**Возрастной рейтинг (IARC):** игра; насилие — мультяшное, без крови (бои духов); общение пользователей — да (чат, модерация
жалобами, скрытие игроков); покупки — да; местоположение передаётся — нет (другим игрокам не показывается).
**Целевая аудитория:** 13+ (в правилах игры — старше 12 лет; «для детей» не отмечать — иначе требования Families).
**Реклама:** нет. **Доступ для проверки:** вход не нужен (гость), игра доступна сразу.

## 6. Как проверить покупки до выпуска

Play Console → Настройка → Тестирование лицензий → добавить почту Google своего телефона. Установить приложение из закрытого
теста, открыть Казну — покупки тестовой картой Google бесплатны и проходят весь путь (сервер проверяет, начисляет, потребляет).
