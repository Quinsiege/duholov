# Фоны экрана входа и экрана загрузки

Настройки лежат в `www/scenes/scenes.json`, картинки — в `www/scenes/login/` и `www/scenes/loading/`.
Пока картинок нет, фон — как во вкладках игры: тёмный лак с тонким узором и мягким сиянием сверху. На экране входа над ним летают светлячки.

## Экран загрузки

Одна картинка на весь экран. Если их несколько, игра берёт случайную или меняет их по дням.

```json
"loading": {
  "images": ["scenes/loading/night-village.jpg", "scenes/loading/forest.jpg"],
  "mode": "random",
  "shade": 0.25,
  "position": "center 30%"
}
```
- `images` — пути к картинкам от папки `www`.
- `mode` — `random` (каждый раз случайная) или `daily` (одна на весь день).
- `shade` — насколько затемнить низ экрана под панелью с советом: 0 — не затемнять, 1 — сильно. Нужно, чтобы текст читался.
- `position` — какая часть картинки важнее, если она не помещается целиком. Например, `center 30%` — ближе к верху.

**Размер:** вертикальная картинка 1080×1920 (или 1242×2688), JPG или WebP, до 400 КБ. Главное держи в середине по ширине: на разных телефонах края обрезаются. Нижнюю треть закрывает панель с советом.

Пока картинка грузится, игрок видит обычный фон, потом картинка плавно проявляется.

## Экран входа

Фон неподвижен (4.6: без сдвига от наклона телефона и без парящих духов). Его можно собрать из нескольких картинок, наложенных друг на друга: небо, холмы, туман, передний план. Над фоном летают светлячки, снег или искры.

```json
"login": {
  "layers": [
    { "src": "scenes/login/1-sky.jpg" },
    { "src": "scenes/login/2-forest.png", "anim": "sway" },
    { "src": "scenes/login/3-mist.png",   "anim": "drift", "opacity": 0.7, "blend": "screen" },
    { "src": "scenes/login/4-front.png",  "fit": "bottom" }
  ],
  "particles": "fireflies",
  "shade": 0.25
}
```
- `layers` — картинки **от дальней к ближней**. Первая обычно небо (JPG), остальные — PNG или WebP с прозрачностью.
  - `anim` — своя анимация слоя: `sway` (покачивание, для деревьев), `drift` (медленный дрейф, для облаков и тумана), `float` (парит), `pulse` (мерцает).
  - `fit` — `cover` (на весь экран, по умолчанию), `bottom` (по ширине, прижат к низу — для земли и травы), `contain`.
  - `opacity` — прозрачность 0…1, `blend` — режим наложения (`screen` — для тумана и света).
- `particles` — `fireflies` (светлячки), `snow` (снег), `embers` (искры) или `none`.
- `shade` — затемнение низа под кнопками, 0…1.

**Размер слоёв:** 1242×2688 (вертикальные). Главное держи в середине по ширине: на разных телефонах края обрезаются. Нижнюю часть закрывают кнопки входа.

## Праздники и сезоны

Для праздника или сезона можно подменить сцену. Первый подходящий вариант заменяет обычные настройки.

```json
"variants": [
  { "when": { "holiday": "svyatki" }, "login": { "particles": "snow" }, "loading": { "images": ["scenes/loading/svyatki.jpg"] } },
  { "when": { "season": "autumn" }, "login": { "layers": [ ... ] } },
  { "when": { "from": "12-20", "to": "01-10" }, "loading": { "images": ["scenes/loading/new-year.jpg"] } },
  { "when": { "night": true }, "login": { "shade": 0.4 } }
]
```
- `holiday` — `svyatki`, `maslenitsa`, `kupala`, `veles`, `pokrov`.
- `season` — `winter`, `spring`, `summer`, `autumn`.
- `from`/`to` — даты «ММ-ДД», можно через Новый год.
- `night` — ночью по времени игрока.

## Как выложить

Картинки кладутся в `www/scenes/…`, пути прописываются в `scenes.json` → Pull Request → после слияния всё появится на duholov.ru. Если в `scenes.json` ошибка, игра покажет обычный фон — ничего не сломается.

Спокойный режим и настройка телефона «уменьшить движение» выключают анимацию. В режиме экономии нет частиц.
