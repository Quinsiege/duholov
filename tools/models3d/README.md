# 3D-модели на карте (5.1.28)

Источник, святилища и Разломы всех восьми мифологий и сам Ловчий — настоящие 3D-модели на карте. Делаются здесь, скриптами
Blender, по рисункам игры (Art.springIcon / shrineIcon / riftIcon / avatar); в игре их рисует `www/js/m3d.js` (свой WebGL, без библиотек).

## Что нужно

- Blender 4.5 LTS (портативный; с download.blender.org из России — 403, качать с зеркал, сверять .sha256).
- Аддон «MCP for Blender» v1.8 (ahujasid/blender-mcp, addon.py): включить в настройках, сервер на `localhost:9876`.
  Blender должен быть открыт — скрипты выполняются в нём через `bl.mjs`.
- Рабочая папка вне репозитория (рендеры, GLB, .blend): `~/Blender/duholov-3d` (или `WORK = r"…"` перед `common.py`).

## Как собрать

```
node tools/models3d/bl.mjs tools/models3d/common.py tools/models3d/rift_celtic.py   # одна модель: сцена, рендер, GLB, .blend
node tools/models3d/bl.mjs tools/models3d/common.py tools/models3d/export_all.py    # все 17 — в www/models/*.m3d
node tools/models3d/bl.mjs tools/models3d/common.py tools/models3d/lineup_all.py    # сводка всех моделей «как на карте»
```

### Обычный Ловчий — модель со скелетом (5.1.40)

Обычный облик Ловчего (`catcher`) — готовая модель из генератора (Meshy, «Shadow Seer»: glTF со скелетом Mixamo и анимациями;
исходник — `~/Blender/duholov-3d/src/catcher_shadow_seer.glb`, в репозиторий не идёт — 28 МБ). Выгружает её не Blender, а
```
node tools/models3d/skinned.mjs ~/Blender/duholov-3d/src/catcher_shadow_seer.glb catcher 1024
```
Сетка — как есть (30 830 треугольников), кости пальцев убраны (их веса — кисти), до 4 костей на вершину; анимации запечены
матрицами костей (30 к/с, в осях игры): `walk` ← Walking, `run` ← Running, `idle` собирается в скрипте (ноги — исходная поза,
корпус и руки — из кадра ходьбы, дыхание), текстура цвета — WebP 1024. Нужен `ffmpeg`. `export_all.py` эту модель не трогает.
В игре её рисует тот же `m3d.js` (шейдер со скелетом: до `M3D.MAXB` костей), клипы смешиваются по походке (стоит / идёт / бежит).
Цвет плаща из облика у неё не меняется — плащ в текстуре.

### Духи со скелетом (5.1.41)

Синий дух (`spirit_blue`) — модель владельца из генератора (скелет SmartRig `Bone_000…068`, без анимаций; исходник —
`~/Blender/duholov-3d/src/spirit_blue.glb`). Анимации на месте делает Blender (`spirit_anim.py`): `hover` — левитация, `fly` —
полёт с наклоном, `dash` — усиленный полёт; выгрузка — `~/Blender/duholov-3d/glb/spirit_blue_anim.glb`. Затем
```
node tools/models3d/bl.mjs tools/models3d/spirit_anim.py
node tools/models3d/skinned.mjs ~/Blender/duholov-3d/glb/spirit_blue_anim.glb spirit_blue 1024 --clips=idle:hover,walk:fly,run:dash "--drop=^Bone_0(29|[3-6][0-9])$" --float
```
Пальцы (`Bone_029…068`) — убраны (веса — кистям), `--float` — дух парит (высота — из анимации, на землю не ставится).
Вершин больше 65535 — сетка делится на части (треугольники те же: 103 379). Походку (стоит / летит / мчится) у духа задаёт
тот, кто им управляет (`v.gait`, `v.yaw` холста модели), как у Ловчего.

### Облики Огненный бес, Изумрудная странница, Самоварный джинн (5.1.41)

Модели владельца из генератора (скелет Mixamo, Walking и Running на месте; исходники — `~/Blender/duholov-3d/src/<облик>.glb`).
- «Отдых стоя» бесу и страннице — `idle_anim.py` (руки опущены — поза из ходьбы, колени чуть согнуты, дыхание, оглядывается;
  у беса подрагивает пламя на голове).
- Самоварному джинну все три анимации — `genie_anim.py`: самовар не гнётся, движется целиком (подскок, перевал с ножки на ножку,
  наклон на бегу, верх-чайник с запаздыванием), машут маленькие ручки и шагают ножки.
- Кости пальцев (у джинна — и цепочек ручек) — прочь из рига прямо в Blender: `strip_fingers.py` (их веса у самой руки — кисти,
  у корпуса, плаща и волос — своим костям: автоскелет вешает пальцы и на соседнее, и всё тянулось; кусок сетки, что больше чем
  наполовину кисть, — отдельно смоделированный большой палец — целиком руке), он же выгружает glb.
- Сваренные перемычки руки — `cut_bridges.py`: генератор сращивает сетку, где кисть касается пояса и плаща; грань «рука — не рука»,
  что в анимациях растягивается больше ×3, — прочь (в исходной позе её не видно, на бегу она — полоска). Треугольников чуть меньше.
```
echo "NAME = 'emerald_wayfarer'" > n.py
node tools/models3d/bl.mjs n.py tools/models3d/idle_anim.py
node tools/models3d/bl.mjs n.py tools/models3d/strip_fingers.py
node tools/models3d/bl.mjs n.py tools/models3d/cut_bridges.py
node tools/models3d/skinned.mjs ~/Blender/duholov-3d/glb/emerald_wayfarer_anim.glb emerald_wayfarer 1024 --clips=idle:idle,walk:walk,run:run
```
Бес — то же с `NAME = 'ember_imp'`; джинн — `genie_anim.py` вместо `idle_anim.py`, а в n.py ещё
`DROP = r'Hand(Thumb|Index|Middle|Ring|Pinky)\d|^Bone_0(1[1-9]|3[12])$'` и `NEAR = True` (кусок сетки у самой кисти — к руке: большой палец генератор привесил к бедру). Облики-модели перечислены в `M3D.LOOKS`; портрет для
кружков аватаров — `www/img/skins/<облик>.webp` (снимок модели в Blender, 256 точек). Конвертер и сам переносит веса убранных
костей по тому же правилу (`--drop`), если риг не чистили в Blender.

### Источник — колодец со скелетом (5.1.41)

Модель владельца из генератора (`~/Blender/duholov-3d/src/spring_well.glb`, 55 621 треугольник): каменная чаша на резном
постаменте, бирюзовая вода, над ней парит осколок Алатыря. Скелет генератора не годится — `spring_anim.py` ставит свой из трёх костей:
`root` (стоит), `crystal` (куски сетки выше чаши — парит, вращается, покачивается), `water` (бирюзовая внутренность чаши по
текстуре — середина «дышит», у бортика вес спадает до нуля), `dry` — неподвижная метка воды. Клипы: idle и dry (в игре — walk/run):
исчерпанный Источник переходит на «пересох» — осколок падает в чашу, вода — цвета сухого камня (шейдер по костям water и dry, `M3D.DRY`).
```
node tools/models3d/bl.mjs tools/models3d/spring_anim.py
node tools/models3d/skinned.mjs ~/Blender/duholov-3d/glb/spring_anim.glb spring 1024 --clips=idle:idle,walk:dry,run:dry
```
На карте — ростом с Ловчего до края чаши (`M3D.PLACE_KS`, `PLACE_H`), поворачивается вместе с картой. `export_all.py` его не трогает.

### Облик Призрачный волк (5.1.41)

Модель владельца из генератора — четвероногий, автоскелет SmartRig на 51 кость, анимаций нет. Всё — `wolf_anim.py`:
- кости — до 32: середина пясти и кончики пальцев передних лап, пальцы задних, лопатки, кончики ушей, каждая вторая кость
  хвоста — сливаются с родителем;
- срощенные лапы: левая и правая касаются, у вершин между ними веса обеих — вершине веса только её стороны, грани-перемычки
  между лапами — прочь (на шаге между лапами тянулась перепонка); веса костей лап на гриве и спине (выше плеча/бедра) и
  у дальних вершин — корню лапы;
- idle — дышит, оглядывается, поводит ушами; walk — шаг (лапы по очереди); run — галоп со сгибом спины. Лапа выравнивается
  к земле в запястье и скакательном суставе (сустав пальцев не поворачивается — рвёт ступню).
```
node tools/models3d/bl.mjs tools/models3d/wolf_anim.py
node tools/models3d/skinned.mjs ~/Blender/duholov-3d/glb/wolf_anim.glb wolf 1024 --clips=idle:idle,walk:walk,run:run
```
Скрипт работает и в фоне, без окна: `blender -b --factory-startup --python tools/models3d/wolf_anim.py`.

## Как устроены модели

- 1 единица = 1 метр, основание — на z = 0, центр основания — точка привязки значка, лицом к −Y (к игроку на неповёрнутой карте).
- Мультяшная обводка — модификатор Solidify `outline` (в Blender); в игре — та же «вывернутая оболочка», но в шейдере:
  в файле её нет, толщина берётся у модификатора, на экране — `M3D.OUTLINE_PX`.
- Движется (по именам объектов): дети пустышки `swirl` — вихрь портала крутится; `*flame*_out/_in` — пламя колышется;
  `wisp_*` — огоньки покачиваются; `shard` — осколок Источника парит; `spark_*` — искры мерцают. Струя и дуги Источника
  (`jet`, `arc_*`) прячутся, когда он исчерпан.
- Ловчий и его облики-скины (`catchers.py`: обычный капюшон и 9 нарядов по рисункам `skins-art.js` — Купальский, Лесной,
  Морозный, Волхв, Богатырь, Вороний, Навий страж, Жар-перо, Княжий; модели `catcher_<скин>`; с 5.1.40 обычный `catcher` — со
  скелетом, см. выше, сцена `catcher` из `catchers.py` в игру больше не выгружается) шагают и бегут
  по пустышкам-шарнирам: `body` — туловище с капюшоном и колчаном (подскок, наклон
  вперёд, покачивание), `arm_p`/`arm_n` — руки от плеч (дети `body`), `leg_p`/`leg_n` — ноги от бёдер; `_p` — сторона +X.
  Походку, поворот и цвета задаёт карта (`M3D.setMe`: heading, gait 0/1/2, look); цвета облика ложатся на материалы
  `catcher_cloak`, `catcher_cloak_dark` (только у обычного наряда) и `catcher_eyes` (у всех). Рука с посохом Волхва —
  шарнир `arm_p_hold`: она в группе туловища и не машет.
- Выгрузка (`export_m3d` в `common.py`) снимает фаски и пропускает детали мельче 6 см (на значке они меньше пикселя),
  сглаживает нормали по углу 30°, квантует позиции (int16) и нормали (int8). Формат — в комментарии к `M3D.parse`.
